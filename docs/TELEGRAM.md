# Telegram 管理入口

通过中文 Bot 按钮查看概览，在 Telegram 内嵌面板管理链路、机器和 sing-box 节点。与网页版共用业务逻辑和数据库，不需要另一套面板。

> 默认关闭。仅绑定的 Telegram 管理员可以使用，群聊不提供管理入口。新增机器时的 SSH 凭据只在内嵌面板表单提交，不要发给 Bot。终端、账户安全设置和审计页不向 Telegram 会话开放。

## 配置与绑定

1. 在 Telegram 官方 `@BotFather` 创建专用 Bot，保存 Bot Token。不要与其他长轮询程序共用同一个 Bot。
2. 从普通浏览器登录 fluxlite，进入 **个人中心 → Telegram Bot**。
3. 填写 Bot Token 和面板的公网 HTTPS 根地址，开启接入。保存时输入当前管理员密码；账号启用 TOTP 时同时输入验证码。Token 保存后不会回显。
4. 生成绑定链接，用自己的 Telegram 账号在私聊中打开并点击 **Start / 开始**。链接有效期五分钟且仅能使用一次，不要转发。
5. 返回个人中心刷新绑定状态，核对绑定的 Telegram 用户 ID。之后向 Bot 发送 `/start`，使用中文按钮查看数据或打开内嵌管理面板。

服务器需要能够访问 `api.telegram.org:443`；用户设备需要能够访问面板 HTTPS 地址和 Telegram Web App SDK。若 Bot 曾配置 Webhook，先由管理员解除 Webhook 再启用长轮询，本功能不会擅自删除其他应用的 Webhook。

## 可以做什么

| 模块 | Bot 聊天 | 内嵌面板 |
|---|---|---|
| 仪表盘 | 汇总及每条链路累计入向/出向/合计，5 条一页 | 查看资源、流量图表和运行状态 |
| 链路 | 分页列表、分步添加、确认部署/停止/删除 | 添加、编辑、下发、验证、停止、删除 |
| 机器 | 资源摘要、填写新增资料、确认删除；SSH 凭据转安全表单 | 添加、编辑、探测、查看资源、删除 |
| 节点 | 分步创建、确认删除和启停 | 创建、扫描接管、启停、额度/期限管理、删除、链接/二维码 |

Bot 内可分步添加链路和代理节点，并直接删除、部署或启停。所有写操作先展示摘要，再使用一次性确认按钮执行；取消、过期、解绑或重启后旧确认失效。新增机器先在聊天填写非敏感资料，再打开安全表单输入 SSH 密码或私钥并提交。不要在聊天里发送服务器凭据。

## 删除的实际影响

- 删除链路：沿用网页版清理逻辑；先核对链路名称和影响再确认。
- 删除机器：仍被链路或其他机器作为跳板引用时禁止删除；会清理该机器上由面板管理的 sing-box 用户服务，随后删除机器记录。Realm 与面板登录公钥可能需要另行清理，不等同于卸载整台机器。
- 删除外部扫描节点记录：不删除原始远程配置。
- 删除已接管/面板管理节点：会删除面板管理的服务和配置，不会自动恢复接管前的共享服务片段。

## 停用、换绑和故障排查

- 在普通网页个人中心关闭接入或解除绑定，已签发的 Telegram 会话随即失效。
- 替换 Bot Token 后需要重新绑定。不要在聊天、截图或日志中公开 Token；泄漏后在 BotFather 撤销并更新。
- 会话过期、页面刷新后提示登录数据已使用时，关闭内嵌面板，从 Bot 按钮重新打开。会话仅保存在内存，不写浏览器永久存储。
- 普通浏览器直接打开 `/telegram` 不会自动登录，也不会回退到已有网页管理员 Cookie。
- Bot 无响应：检查启用状态、绑定 ID、服务器到 Telegram 的网络以及是否存在另一个轮询进程/Webhook。
- 内嵌面板无法打开：检查 HTTPS 证书、反向代理和安全头。`/telegram` 允许 Telegram Web 的框架嵌入与官方 SDK，普通网页仍禁止被嵌入；代理不要为 `/telegram` 额外强制覆盖为 `X-Frame-Options: DENY`。

## 安全与部署

Bot 配置用面板现有主密钥加密保存在 SQLite。后台验证 Telegram `initData` 的 HMAC、签发时间和绑定用户 ID，然后签发短期、权限受限的 Bearer 会话。不能通过修改前端地址获得终端或账户设置权限。Telegram 的变更操作进入现有审计日志。

数据库升级追加集成表；原有配置与节点不变。部署前备份数据库、主密钥与旧二进制。未填写 Token 时不会启动 Telegram 轮询，不影响现有网页。

## Bot 直接操作步骤

- 发送 /start，选择链路、机器或节点菜单。列表可分页，每项显示编号，重名资源按编号区分。
- 点击添加，根据提示逐步填写；输入错误会提示重填。随时发送 /cancel 或点取消结束。
- 链路按顺序选择跳点，填写目标、协议、端口与额度。确认创建只保存停用草稿，之后点击部署并再次确认才启动。完整部署成功才标记启用；配额暂停或耗尽时拒绝启动。
- 新建代理节点选择机器、协议、端口、额度、有效天数后确认创建并部署。
- 新增机器的资料保留 10 分钟；点击安全填写 SSH 凭据后会自动填入表单。密码/私钥保持空白，需要手动填写。
- 删除确认明确区分外部扫描记录与托管服务。期间目标或关联托管节点变化时，旧确认拒绝执行，请重新选择。
- 仪表盘显示累计用量，并标注中继采样和未采集数据；不是本月额度用量。
- 服务升级会使正在填写的向导和确认按钮失效，但保留 Bot 配置和绑定。重新发送 /start 即可。
